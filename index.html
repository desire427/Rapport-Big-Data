Q7 : Parquet n'est pas toujours le meilleur choix. CSV est ideal pour l'echange universel et la relecture humaine. JSON convient aux APIs et donnees hierarchiques. Parquet est optimal pour le Big Data et Spark.

Q8 : Pour un reseau social generant 10 milliards d'evenements/jour, le format Parquet est recommande pour sa compression (reduction des couts) et ses performances en lecture colonnaire.

Q9 : La relation taille/temps n'est pas lineaire (sous-lineaire). Cela implique que les technologies Big Data passent bien a l'echelle, mais que des volumes massifs necessitent des architectures distribuees (Spark, Hadoop).

3. Premier Job MapReduce

Ce qui etait demande : utiliser mapper.py et reducer.py en Python.

mapper.py

#!/usr/bin/env python3
import sys
for line in sys.stdin:
    line = line.strip()
    if line.startswith('VendorID'):
        continue
    cols = line.split(',')
    try:
        pickup = cols[1]
        heure = pickup[11:13]
        print(f'{heure}\t1')
    except:
        pass

reducer.py

#!/usr/bin/env python3
import sys
heure_courante = None
total = 0
for line in sys.stdin:
    heure, count = line.strip().split('\t')
    if heure == heure_courante:
        total += int(count)
    else:
        if heure_courante:
            print(f'{heure_courante}\t{total}')
        heure_courante = heure
        total = int(count)
if heure_courante:
    print(f'{heure_courante}\t{total}')

Probleme rencontre :

  • Python3 n'est pas installe sur les conteneurs Hadoop (Debian Stretch, depots hors ligne)
  • Erreur : Cannot run program "python3": error=2, No such file or directory

Solution de contournement : AWK

AWK est present sur tous les systemes UNIX. Transformation :

Python AWK
line.split(',')-F','
line.startswith('VendorID')NR>1
cols[1]$2
pickup[11:13]substr($2,12,2)
print(f'{heure}\t1')print $2 "\t1"

Commande finale :

hdfs dfs -rm -r /tp1/output/courses
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-*.jar \
  -input  /tp1/data/taxi.csv     \
  -output /tp1/output/courses    \
  -mapper  "awk -F',' 'NR>1 {print substr($2,12,2) \"\t1\"}'" \
  -reducer "cat"

Post-traitement et resultat :

Solution apportee

Utilisation de AWK comme solution de contournement, produisant des resultats identiques aux scripts Python demandes.

Lecons apprises

  1. Verifier les dependances logicielles dans les conteneurs Docker
  2. Savoir trouver des solutions alternatives (AWK) lorsque l'approche initiale echoue
  3. AWK est un outil universel sur tous les systemes UNIX
  4. La validation croisee (Pandas, Hadoop, PySpark) confirme la coherence des resultats
